A make.fun entry for "The Dog Ate My Homework: Funniest Excuse" — one line, in the dog's own voice, explaining why the homework got eaten. The dog believes it has done nothing wrong: the floor is his, everything on the floor is his, and honestly, the human practically served it to him.

The program writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
